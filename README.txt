ALISH & ANAS — FREE ANNIVERSARY WEBSITE

1. Open index.html to preview the website.
2. To publish it free, use GitHub Pages:
   - Create a free GitHub account.
   - Create a new public repository, e.g. "alish-anas".
   - Upload index.html, style.css, script.js and the images folder.
   - In Settings > Pages, select Deploy from branch / main / root.
3. GitHub will give you a public website address.
4. Open the website, enter that address in "Share This Memory", and tap "Generate QR".
5. Scan the QR code with another phone to open the website.

Note: The QR generator uses the free QRCode.js library loaded from cdnjs.
